# Dr.Coder

Dr.Coder is a personal projects hub designed primarily for non-technical clients and visitors.

The project focuses on a clean, highly animated UI that presents projects and technical work in a visually engaging and professional way, making the value of each project understandable without requiring technical knowledge.

## Focus

* Clean and modern UI
* Smooth animations and interactions
* Client-friendly project presentation
* Responsive design
* Professional visual identity

## Technology Stack

* React
* Next.js
* TypeScript
* GSAP
* Tailwind CSS

## Purpose

Dr.Coder serves as a visual portfolio and client-facing showcase, turning technical projects into an accessible and compelling presentation of my work.
